## Direção visual

* sofisticada;
* moderna;
* gastronômica;
* tecnológica;
* limpa;
* profissional.

Evitar:

* dashboard SaaS genérico;
* excesso de gradientes;
* excesso de cards;
* cores sem significado;
* aparência infantil.

Referências conceituais:

* Linear
* Stripe
* Square
* Toast
* Vercel

Não copiar.

## Dashboard

Prioridade visual:

1. O que precisa da minha atenção?
2. Como o negócio está agora?
3. O que mudou?
4. O que provavelmente acontecerá?
5. O que devo fazer?
6. Qual ação posso executar?

Quando adequado, utilize também a Skill existente `ui-ux-pro-max` em conjunto com `toasty-ui`.
